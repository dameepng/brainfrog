# BrainFrog examples

- `@file` parser: a path with spaces resolves as one path and preserves contents; verify malformed input reports a useful error.
- `/rules` resolution: project file takes effect in the documented scope; unrelated repo content cannot silently become a higher-priority instruction.
- Command cancellation: a child process exits and the prompt becomes usable again.

Test the property the user experiences. A temporary test script is acceptable when there is no test framework; avoid building a new harness for a single case.
